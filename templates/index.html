Implementation Roadmap
Phase 1: Foundation COMPLETED

Config, database models, Supabase schema SQL, seed data, detection modularization, and clean factory architecture.

Phase 2: Authentication & RBAC NEXT

2FA one-time code, 15-minute inactivity session timeout, password hashing, role checks, and login audit logs.

Phase 3: Threat Detection UPCOMING

11 heuristic rules, employee inbox & quarantine views, on-demand raw text email scanner with indicator breakdown.

Phase 4: Incident Response UPCOMING

'Report Phishing' button, admin triage workflow, block sender, flag compromised victim accounts, and alert staff.

Phase 5: Phishing Awareness UPCOMING

Tracked simulated campaigns, zero-credential-capture training landing pages, quizzes, and employee readiness scoring.

Phase 6: Dashboards & CSV Export UPCOMING

SOC executive dashboards, manager team analytics, high-risk user detection, and CSV audit reports.
